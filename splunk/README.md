# Splunk SIEM Analysis

This directory contains Splunk-related configuration,
search queries, and investigation notes for the Virtual SOC Lab.

## Log Sources

- Authentication logs
- Web server logs
- Network telemetry logs
- SOC alert logs

## Detection Use Cases

1. Multiple failed login attempts
2. Possible brute-force activity
3. HTTP 403 events
4. Network connection monitoring
5. DNS activity analysis

## Objective

Use Splunk as a SIEM platform to ingest security telemetry,
search events, identify suspicious activity, and support
SOC investigation workflows.
